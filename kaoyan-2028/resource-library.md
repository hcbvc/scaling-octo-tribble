# 八、2027年的调整原则

当你的研究方向逐渐明确之后，再从资源库里抽取对应路线。

例如：

- 偏凝聚态 → 固体 + 量子 + 统计 + 数值 + 群论
- 偏原子光物理 → 量子 + 光学 + 电磁 + 群论
- 偏粒子/核 → 量子 + 相对论 + 群论 + 场论
- 偏引力/宇宙学 → GR + 微分几何 + 张量 + PDE
- 偏理论/数学物理 → PDE + 复分析 + 泛函分析 + 微分几何
- 偏计算/交叉 → Python + 数值方法 + ODE/PDE + 对应物理课程

这些只是后续学习路径的示例，不代表你现在已经确定任何方向。

## 资源库维护规则

每次发现更合适的教材或课程：

- 不立即新增
- 先比较与当前主资源的重合度
- 确定更适合后再替换
- 同一门课不要无限堆资源

**目标不是拥有最大的课程库，而是拥有一套真正能学完的课程库。**
