# 2028考研｜面向凝聚态与光电工程的基础计划（2026-10-01 修订）

> 目标方向：凝聚态/材料物理、光学/光电信息、光电材料与器件等偏应用方向。理想培养单位：国科大杭州高等研究院（杭高院）。
>
> 本文件是原“本科物理全景图”的可执行修订版。2028招生目录尚未发布，专业代码、承办单位、招生方向、考试科目和招生人数都要以报考年份的国科大及杭高院正式目录为准；下列2026科目只用于规划共通基础，不是对2028考试的承诺。

## 一、目标路径与招生信息核对

“凝聚态”和“光学/光电工程”不是一条完全相同的考研路线。先把方向缩成两个候选，不再默认准备所有物理分支。

| 方向候选 | 2026年国科大科目设置参考 | 备考内容含义 |
| --- | --- | --- |
| 凝聚态物理（070205） | 政治、英语一、数学二、固体物理（809） | 数学二基础、固体物理、量子与热统基础 |
| 光学（070207） | 政治、英语一、高等数学（604）、光学（817） | 微积分、光学、电磁学、Fourier基础 |

以上是国科大公布的2026年初试科目设置。具体到杭高院、承办学院/研究所和2028年份时，招生目录可能不同，必须逐项复核。杭高院官方招生介绍将其定位为物理光电等领域的交叉型培养单位，并说明部分学术型硕士由承办单位招生；因此“在杭高院学习”与“招生专业代码/学籍或承办单位”要分开核实。

**2027年招生信息审计时，必须查：**
1. 2028招生目录里哪些单位实际招收目标专业；
2. 专业代码、研究方向、导师和实际承办单位；
3. 初试科目及官方考试大纲；
4. 报考条件、推免/统考名额和培养地点；

## 二、现在学什么，暂缓什么

### 共同基础（现在到2027年方向审计前）

1. **英语**：持续积累词汇、句法和阅读。先练扎实阅读，不因未来可能考英语二而停掉英语一难度的基础材料；方向确定后再切换对应真题。
2. **数学**：微积分和线性代数是当前共同主线。按2026参考，数学二是凝聚态和多数工程方向的重要候选；若最后考虑070207光学，则另按官方大纲补齐高等数学要求。暂缓完整概率论，等目标目录明确后再决定是否投入。
3. **普物必要部分**：力学、电磁学、波动与光学基础，为专业课提供支撑。普物用于补洞和建框架，不和专业课重复刷两遍。
4. **Python/数据处理**：每周少量练习，用于画图、拟合、数值积分和处理实验数据；不单独扩成计算机大课程。

### 两条专业课主线

**A. 凝聚态/材料/半导体**
- 先修：线性代数、微积分、普通物理、电磁学基础；
- 主干：量子力学入门 → 晶体结构与倒格子 → 声子 → 自由电子模型 → 能带与半导体；
- 支撑：热力学与统计物理基础、材料结构/性质、实验表征与数据分析；
- 后续可选：输运、磁性、低维材料、光电材料与器件，按目标导师方向决定。

**B. 光学/光电信息工程**
- 先修：微积分、线性代数、波动与电磁学；
- 主干：几何光学 → 干涉与衍射 → 偏振 → Fourier光学 → 光学（817）大纲/题目；
- 工程支撑：基础电路与电子学、半导体和光电探测器件、激光/光纤/成像中与目标方向相关的模块；
- 后续可选：微纳光学、光子器件、光学系统、光谱测量、信号处理，按目标导师方向决定。

**暂缓到目标和基础更清楚以后：**
广义相对论、张量与微分几何、泛函分析、群论、流体力学，以及理论力学的高阶Hamilton形式。它们是有价值的知识，但目前与目标方向和可能初试科目的距离较远。ODE、Fourier等只学到服务力学、光学、电磁和计算的程度，不单独追求数学专业深度。

## 三、执行节奏：先恢复，再加量

原计划的“每天10小时模板”不作为当前日目标。先连续两周记录真实可持续学习时长，再逐步增加。

### 第1周：重启
- 每天2个25分钟学习块：英语 + 数学；
- 状态差时完成10分钟也记为最低完成；
- 手机在学习块开始前放到另一个房间；
- 不补过去漏掉的章节。

### 第2—4周：建立稳定节奏
每周学习5—6天，每天从3个25分钟学习块开始：
- 英语：1块；
- 数学：1块；
- 专业基础：1块，凝聚态与光学各做一次体验，再选一个作为本月主线；
- 每周另做1—2块复习/错题整理；
- Python最多每周1—2块，服务于当前学科内容。

只有在一周至少5天完成计划时，下一周才增加一个学习块。没达到就维持，不用加倍补课。

### 2026年10月：共同基础与方向体验
- 英语、微积分、线性代数为固定主线；
- 普物力学/电磁学作为补基础；
- 凝聚态和光学各安排短体验课/基础章节，记录“能否理解、是否想继续、对应的工程应用是什么”；
- 暂不同时启动GR、流体、复分析等新课。

### 2026年11月：暂定一个主方向
按实际体验和杭高院公开导师/研究方向，暂定一个主线（凝聚态材料或光电），另一个每周保留一次接触。
- 凝聚态主线：固体物理 + 量子基础 + 数学；
- 光电主线：光学 + 电磁基础 + 数学；
- 每周留一个小成果：一页知识图、3道错题复做、一个Python图或简短讲解。

### 2026年12月：巩固与校准
- 不以“把13门课都学一遍”为验收目标；
- 对当前主线做章节回忆和基础题；
- 完成一个小作品：例如干涉/衍射模拟图、材料能带概念图、简单光谱数据绘图；
- 写出“当前第一候选、第二候选、还缺什么信息”；
- 复核最新杭高院招生页面，但不提前锁定2028考试科目。

## 四、每周检查和每日记录

每周只看四个指标：
1. 完成了几天；
2. 英语与数学各有多少有效学习块；
3. 专业课留下了什么可检查的产出；
4. 下周要继续、缩小还是调整哪一项。

每日记录压缩为三行：
- 学习块与产出：
- 今天卡住的一点：
- 明天第一步：

复习采用当天回忆、隔天回忆、周末抽测；数学和专业课在基础掌握后混合不同类型的题。计划的作用是帮你行动和纠偏，不用靠补齐日历证明自己。

## 五、现阶段资源规则

- 英语：一本主词汇/语法资源 + 一套阅读材料；
- 数学：一本主教材 + 一套基础题；
- 专业课：先按方向各选一门主课和一本主教材，方向定下来后只留一条主线；
- Python：只学当前任务需要的语法、NumPy和绘图；
- 每科不同时追多门网课。看完一个知识点后必须留下回忆、题目或图表产出。
