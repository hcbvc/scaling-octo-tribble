# 2028考研学习系统

目标：2028年研究生入学考试。

当前策略：先系统接触数学、物理、英语和编程，积累基础与学习体验，再结合招生目录选择重点方向。国科大杭州高等研究院（杭高院）是理想培养单位之一；现阶段不提前锁定专业或考试科目。
