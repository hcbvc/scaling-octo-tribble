# 2028考研学习系统

目标：2028年入学。以全国高校与科研院所为候选范围，先完整接触数学、物理、英语和编程的主要基础，再按专业方向与正式招生目录选择考试路线。国科大杭州高等研究院是理想候选单位之一。
