## 一、每天10小时的固定框架

| 科目 | 日均 | 周均 | 当前任务 |
| --- | ---: | ---: | --- |
| 数学一 | 3.0h | 21h | 打基础+例题+闭卷回忆 |
| 英语一 | 2.5h | 17.5h | 词汇、语法、长难句、基础阅读 |
| 量子力学 | 1.75h | 12.25h | 第一轮体系建立 |
| 普通物理 | 1.5h | 10.5h | 力学/电磁/热学/光学轮廓 |
| Python | 0.5h | 3.5h | 基础语法+科学计算 |
| 日复盘 | 0.75h | 5.25h | 错题、回忆、计划调整 |
| **合计** | **10h** | **70h** | |

**执行原则**：10小时是上限目标，不是“坐在桌前10小时”。每个学习块都必须有可验收产出。

## 二、每日模板

- 08:00–10:00 数学：新知识 + 例题
- 10:15–11:45 英语：词汇 + 语法/长难句
- 11:45–12:15 英语：闭卷回忆当天词汇
- 14:00–15:00 数学：习题/错题
- 15:15–17:00 量子力学
- 17:15–18:45 普通物理
- 20:00–20:30 Python
- 20:30–21:15 英语阅读/长难句
- 21:15–22:00 当日复盘与间隔复习

每学习50–60分钟休息5–10分钟。每周至少保留半天低负荷/休息时间。

## 三、9月22日—10月31日：启动期

### 数学一
目标：建立完整框架，不追求难题。
- 高等数学：极限、连续、导数、微分、中值定理、积分
- 线性代数：矩阵、行列式、向量组、线性方程组
- 概率论：随机事件、概率、随机变量基础
- 每天至少完成“看懂→遮住资料复述→独立做题”三步。

### 英语一
由于你的英语基础较弱，第一阶段不急着整套真题。
- 每天新词 + 前几天词汇的间隔复习
- 补核心语法
- 每天2–4个长难句精读
- 从短阅读逐渐过渡到考研真题句子

### 量子力学
按“概念—推导—题型”建立骨架：
1. 波函数与概率解释
2. 薛定谔方程
3. 一维势阱/势垒
4. 算符与本征值
5. 测量与不确定关系

### 普通物理
优先力学和电磁学：
- 牛顿力学、动量、角动量、能量
- 静电场、静磁场、电磁感应
- 同时建立公式的物理意义，而不是只背公式

### Python
学习：
- 变量、条件、循环、函数
- list/dict
- NumPy 基础
- matplotlib 基础
每周做一个与数学/物理有关的小练习。

## 四、11月1日—11月30日：强化期

### 数学
进入“章节题 + 闭卷回忆”。
- 每周完成一次章节限时训练
- 错题必须标记：概念错 / 计算错 / 方法错 / 审题错
- 每周末重新做本周最典型的5–10道错题

### 英语
- 词汇继续间隔复习
- 长难句增加到每天3–5句
- 开始稳定做考研英语阅读真题，但重点是分析句子和选项逻辑，不追求速度

### 量子力学
继续：
- 中心力场
- 角动量与自旋
- 矩阵表示
- 简并、微扰等后续核心内容按教材进度推进

### 普通物理
完成力学、电磁学主干，开始热学/光学。

### Python
开始用Python验证：
- 矩阵运算
- 数值积分
- 函数绘图
- 简单物理模型

## 五、12月1日—12月31日：第一轮收口

月底不要再无限开新章节，而是把知识变成“可调用能力”。

每周：
1. 1次数学综合训练
2. 1次英语阅读训练
3. 1次量子力学闭卷知识图
4. 1次普通物理公式/模型默写
5. 1次Python小项目
6. 1次周复盘

### 12月31日验收

**数学**：能够不看书说出三大模块的知识树，基础题能够独立完成。

**英语**：核心词汇形成稳定复习循环，能够独立拆解基本长难句，并开始适应考研阅读。

**量子力学**：能够从波函数、薛定谔方程、算符、角动量等核心概念出发进行基本推导和解题。

**普通物理**：形成力学、电磁学、热学、光学的总体框架。

**Python**：能够独立写简单科学计算脚本并画图。

## 六、真正执行时采用“输入—输出”制

不要用“今天学了3小时”判断完成度。

每天记录：
- 数学：完成章节/题数/正确率
- 英语：新词数/复习词数/长难句数/阅读正确率
- 量子：知识点/推导/题目
- 普物：章节/题目
- Python：代码是否独立写出
- 当天最大错误是什么

**最重要的一条**：每天最后45分钟必须有闭卷回忆。研究证据支持检索练习和间隔学习对长期保持有帮助，因此本计划把“回忆”而不是重复看书作为复习主线。

## 七、周循环

**周一—周六：正常10小时。**

**周日：**
- 4–6小时轻量复习
- 整理错题
- 做一次周测
- 根据结果调整下一周
- 剩余时间休息

不要连续7天硬顶10小时。长期备考需要可持续性。
