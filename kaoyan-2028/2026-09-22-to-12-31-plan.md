## 一、为什么现在先“广学”而不是先定方向

你现在的首要任务不是证明自己适合某一个方向，而是：

**先建立完整的本科物理知识地图 → 亲自体验不同分支 → 发现自己更喜欢什么、擅长什么 → 再结合目标院所的招生科目和导师方向做决定。**

所以：

- **固体物理 ≠ 默认考凝聚态**。它只是本阶段重要的专业基础课之一。
- **广义相对论 ≠ 默认考理论/引力方向**。它是拓宽理论视野的一门课。
- **计算物理 ≠ 默认走计算方向**。它首先是训练数值思维和科研工具能力。
- 2026年这一轮允许你“全部走一遍”，但不要求你现在就给未来方向贴标签。

### 方向探索的正确顺序

**先学课程 → 形成体验 → 做小项目 → 看研究问题 → 再定方向。**

到2026年12月底，只需要形成一个初步的“方向候选地图”，不要求作最终决定。

## 五、英语：当前阶段的第一重点项目

你目前英语基础薄弱，因此英语不能按普通本科生节奏处理。

### 英语日均3.5小时

**60分钟：词汇**

- 第一阶段每天约35个新词
- 同时复习旧词
- 重点不是“看过”，而是主动回忆

**60分钟：语法 + 长难句**

- 从句
- 非谓语

- 前期：短文本 + 基础理解
- 中期：文章结构 + 证据定位
- 后期：考研阅读语境 + 计时

**30分钟：闭卷复习**

- 词汇主动回忆
- 长难句重新拆
- 阅读错题归因

## 十四、复习机制：主动回忆 + 间隔 + 交错

本计划使用：

**理解 → 当天闭卷回忆 → 隔1天 → 隔3天 → 隔7天 → 隔14天 → 交错练习**

### 一个知识点至少经历

- **D0**：当天10分钟闭卷写出概念/公式
- **D1**：5–15分钟快速重建
- **D3**：做1–3道代表题
- **D7**：混合进周测
- **D14**：再次随机抽查

数学和物理尤其采用交错练习：

不要连续刷大量完全同型题，而是把不同章节的题混合，让自己真正判断“该用哪一种方法”。

这里把间隔和交错当作默认学习机制，而不是万能公式。已有研究支持其在不少STEM与物理学习场景中的潜在收益，但具体效果会因课程、练习形式、反馈和学习者行为而变化。

## 二十二、12月31日总验收

第一轮结束时，不问：

> “我是不是已经把所有课程学完了？”

而问：

> **“我是不是已经有一张完整的物理地图，并且知道自己下一步该深入什么？”**

达到下面这个状态，就算第一轮成功：

**数学有骨架，英语开始能读；普通物理有全局图；量子、经典、电磁、热统形成理论主干；固体成为重要专业基础而不是方向承诺；流体、光学、广义相对论完成第一轮入门；Python和计算物理开始真正服务物理学习；同时对不同研究方向形成初步认知。**

2027年再把其中与你最终正式初试科目相关的部分集中升级到：

**教材 → 章节题 → 真题 → 专项训练 → 套题 → 模拟考试。**
